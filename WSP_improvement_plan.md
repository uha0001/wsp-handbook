# WSP Improvement Plan

This document tracks planned improvements, maintenance tasks, software requests, and infrastructure discussions for the WSP server.

The goal is to improve:
- reproducibility of computational workflows,
- onboarding of new users,
- resource management,
- documentation,
- and overall user experience.
