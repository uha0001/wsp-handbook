# WSP Handbook

This repository documents the WSP server, common workflows, and computational practices used in the lab.

The purpose is to provide a practical reference for setting up, running analyses, organizing projects, and troubleshooting common issues.

## Topics

- Getting started
- Connecting to WSP
- Linux basics
- File organization
- Software
- Resource management
- Project templates
- RNA-seq workflow
- Troubleshooting
- FAQ

## Scope

This handbook focuses on practical usage rather than Linux theory. Commands are accompanied by short explanations and examples where appropriate.

## Contributing

This documentation is intended to evolve as new workflows and solutions are developed.
