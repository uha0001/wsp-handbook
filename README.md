# WSP Handbook

A collection of documentation, templates, and scripts for working with the WSP server and computational biology workflows.

This repository is intended to serve as a personal knowledge base that gradually evolves into a practical reference for new lab members. It focuses on documenting common workflows, organizing computational projects, and automating repetitive tasks.

---

## Goals

- Document WSP setup and usage
- Create clear onboarding documentation
- Standardize computational project organization
- Develop reusable analysis scripts
- Maintain templates for common bioinformatics workflows
- Record practical lessons learned during day-to-day research

---
